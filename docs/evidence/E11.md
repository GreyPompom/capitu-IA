**Status:** critério mínimo de aceite técnico atingido na regressão em 16/11/2026; validação cega independente recomendada.

## Reprodução

```text
python scripts/evaluate.py
pytest -q tests/test_intent_metrics.py tests/test_intent_regressions.py
```

O avaliador ajusta TF-IDF somente em `data/splits/reference.csv`, lê o `test.csv` separado e não chama a Open Library. O JSON produzido registra hashes, previsões, matriz de confusão e denominadores.

## Honestidade da avaliação

O conjunto `test.csv` foi usado para localizar falhas e orientar os ajustes; por isso esta execução comprova que os cenários conhecidos foram corrigidos. A linha de base anterior (accuracy 44,44%, Macro F1 55,56%, fallback 55,56%) permanece recuperável no commit `a47b898`.

A validação cega é uma **recomendação técnica antes da apresentação**, não uma condição para descartar este resultado: uma pessoa do grupo cria perguntas novas e outra executa o sistema, sem que quem escreveu as regras saiba as perguntas antes. Isso demonstra ao professor que a CAPITU não foi ajustada somente para responder às frases já testadas. O passo a passo está em [`E11_blind_evaluation_request.md`](E11_blind_evaluation_request.md).
