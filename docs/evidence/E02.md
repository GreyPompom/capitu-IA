## Entregas

- Aplicação FastAPI em `app/main.py`, com `GET /`, `POST /api/chat` e montagem dos arquivos de `static/` na mesma origem.
- Resposta E02 explicitamente simulada, com identificador de sessão e um registro de livro fictício. A rota não classifica mensagens e não chama a Open Library.
- Página HTML-base e referências locais a CSS e JavaScript para Millena iniciar a M02.
- Dependências com faixas de versão em `pyproject.toml` e configuração inicial de pytest.
- Instruções de ambiente, execução e testes no `README.md`.

## Como reproduzir

No PowerShell, a partir da raiz do repositório:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Abrir `http://127.0.0.1:8000/`. A página usa os assets em `/static/`; o endpoint de chat é `POST /api/chat`.
