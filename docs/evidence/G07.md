## Comandos para reprodução independente

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe scripts\build_index.py
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Abra `http://127.0.0.1:8000/`. Em outra janela de terminal, execute:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\run_g05_acceptance.py --mode fixture
.\.venv\Scripts\python.exe scripts\run_g06_reproduction.py --repeats 3
```
