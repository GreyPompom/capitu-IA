# Requisitos e rastreabilidade

A especificação completa, os critérios da A3 e o mapeamento entre requisitos e evidências estão no [planejamento detalhado da equipe](CAPITU_Planejamento_Detalhado_Equipe.md). Esta página é um índice de consulta; altere o planejamento e este índice juntos quando os requisitos forem atualizados.

## Requisitos funcionais acordados

- Buscar livros por título.
- Listar obras associadas a um autor.
- Descobrir livros por assunto ou gênero.
- Consultar detalhes disponíveis de uma obra/edição.
- Esclarecer pedidos incompletos ou ambíguos e permitir selecionar um resultado.
- Responder com transparência quando a Open Library não retorna um campo, está indisponível ou não encontra correspondências.

## Requisitos de IA/PLN

A CAPITU implementará interpretação própria com pré-processamento, TF-IDF, similaridade textual, política de limiar/margem, extração de entidades e regras de diálogo. A API bibliográfica fornece dados, mas não substitui o mecanismo de IA.
